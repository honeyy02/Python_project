# Python CI Pipeline with Testing 🚀

## 📌 Overview
This project demonstrates a CI pipeline using Jenkins to run automated tests and generate code coverage reports for a Python application.

---

## 🚀 Workflow
1. Install dependencies
2. Run test cases using pytest
3. Generate coverage report
4. Archive artifacts

---

## 🛠️ Tech Stack
- Python
- Pytest
- Jenkins

---

## 📂 Project Structure
```
app/
tests/
Jenkinsfile
```

---

## 📊 Features
- Automated test execution
- Code coverage report generation
- Artifact archiving in Jenkins

---

## 📌 Key Learnings
- CI pipeline for testing
- Test automation with pytest
- Coverage tracking
- Jenkins artifact management
